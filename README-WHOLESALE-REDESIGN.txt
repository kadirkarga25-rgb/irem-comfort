İREM COMFORT — PREMIUM TOPTAN ANA SAYFA REDESIGN

Bu patch ana sayfayı üretici/toptan satış odaklı premium bir B2B tasarıma geçirir.

Yapılanlar:
- Yeni WholesaleHome ana sayfası
- Hero, koleksiyonlar, toptan çalışma modeli, konfor teknolojisi, üretim, katalog CTA ve toptan iletişim blokları
- Mevcut ürün/koleksiyon verileri kullanılmaya devam eder
- Ürünler korunur; perakende satın alma yerine toptan bilgi/iletişim akışı öne çıkar
- Header sadeleştirilir ve ana CTA Toptan Sipariş olur
- Eski announcement ticker kaldırılır; eski Trendyol duyurusu görünmez
- Footer Trendyol butonu kaldırılır
- Ürün modalındaki Trendyol satın alma butonu kaldırılır
- İletişim sayfasındaki Trendyol kartı kaldırılır
- Floating Assistant içindeki Trendyol butonu ve hızlı soru kaldırılır
- site_settings.json bu patch içinde yoktur ve değiştirilmez

Uygulama:
1) ZIP içindeki dosyaları mevcut projenin üzerine kopyala.
2) public/site_settings.json dosyasına dokunma.
3) git diff ile kontrol et.
4) git add src ... ile sadece kaynak değişikliklerini commit et.
